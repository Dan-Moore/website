## Getting Started
Astro comes with several templates out of the box, run the create astro command to start reviewing what Astro can do.

```bash
npm create astro@latest
```

| Template | Description |
| ---      | --- |
| Basic    | Simple hello world example |
| Blog     | Example on using Astro's collections |
| Docs     | Documentation template using [Starlight](https://starlight.astro.build/) |
| Minimal  | Bare-bones Astro project |
